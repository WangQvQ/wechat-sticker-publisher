# 嘴硬小鹅：GIF示例

此处公开16张AI生成的大鹅动态表情，配套 [整套循环预览](preview.gif) 与 [文件清单](manifest.json)。原始命名保留，方便对应表情编号。

![嘴硬小鹅动态预览](preview.gif)

**已知问题：用户反馈部分动作存在非预期漂移。** 本组用于展示文件组织、GIF格式和视觉验收问题，不代表所有动作已通过质量检查，也不代表已通过微信审核或已上架。

单张为240×240、透明背景、无限循环GIF。程序检查能确认技术属性，无法仅凭检查通过就证明角色不漂移。

这些示例已获本项目作者同意随仓库公开，适用根目录MIT许可证。使用者需自行完成拟投稿作品的质量与权利检查。
